# 3D 场景查看器 · 使用说明（测试版）

把游戏内某一时刻的 2D 场景快照，转成可交互的 3D 体素切片网页。基于本地 three.js（r147 UMD），**双击 `index.html` 即可打开，离线可用**，不依赖 CDN 与本地服务器。

## 一、从游戏导出场景快照

1. 在游戏里把场景布置成想要的样子（可按 `⏸` 暂停后微调）。
2. 点击底部工具栏的 **快照** 按钮。
3. 浏览器会下载一份 JSON 文件（文件名形如 `元素沙盒-场景-2026-09-27T….json`），内含：
   - `format` / `version` / `exportedAt`：格式标识、游戏版本、导出时间
   - `width` / `height`：网格尺寸
   - `cells`：逐格物质 id 数组（行优先，`0` 为空格）
   - `palette`：物质 id → 名称、颜色、是否自发光

## 二、在查看器中打开

- 双击 `index.html`（或任意静态方式打开）。
- 点 **加载快照 JSON** 选择第 1 步下载的文件；或点 **加载示例火山快照**（`samples/` 内置一份）。
- 交互：左键旋转 · 滚轮缩放 · 右键平移。

## 三、参数说明

| 参数 | 作用 |
|---|---|
| 切片厚度（1~12） | 整幅切片的立体厚度。加大后，地面类物质（石/沙/木/土）向下延伸，形成基座 |
| 降采样（2×2 合并） | 4 格合并为 1 个大方块，实例数降为约 1/4，性能优先时使用；默认关闭 |

## 五、背景说明

星点用 3D 点云撒在大球面上（真实 3D 背景星空）。远山剪影属于 2D 主题装饰层，按既定方案不纳入 3D 场景。

## 六、目录结构

```
viewer/
├── index.html          # 查看器页面（双击打开）
├── viewer.js           # 查看器逻辑
├── node_modules/three/ # 本地 three.js r147（UMD 构建 + examples 版 OrbitControls）
├── samples/
│   ├── volcano.json    # 示例火山快照（游戏内导出）
│   └── volcano.js      # 同内容的脚本包装（供离线自动加载）
└── screenshots/        # 验证截图
```
