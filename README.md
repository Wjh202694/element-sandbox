# 元素沙盒

**在线游玩：https://wjh202694.github.io/element-sandbox/**

涌现式像素物理解压小游戏。沙、水、火、油、植物、熔岩、火药、盐、酸在手机屏幕上相生相克——放火烧山、引水浇灭、种树成林、沙遇熔岩化玻璃、火药殉爆冲天，画面每一秒都不重样。

**特色玩法：配方发现图鉴** —— 首次触发某个元素反应（如火×水→蒸汽）时弹出「新发现」，共 36 条收集目标（含火药受潮、酸皂化、玻璃重熔、毒雾、盐渍枯萎、融雪、导电、闪玻璃、电解、金属导体、蚀刻、电解得氢、氢爆、结冰、融冰、雪崩、暴风雪），让沙盒从玩具变成有探索目标的游戏。

**成就系统** —— 40 个成就、我的世界同款三档分级（常规 14/目标 16/挑战 10），达成时右上角滑入 MC 式弹窗（图标+等级色边框+成就名），成就图鉴按档分组展示进度。统计（涂布量/反应次数/规模峰值/游玩时长/地图生成/3D 使用/海啸经历）持久化到 localStorage。

**七款可切换背景主题** —— 右上「背景」菜单切换并记忆选择：经典夜空（默认）/ 深夜星空（星点明灭+流星）/ 极光之夜（波动光幕，绿青紫流转）/ 白天雪山（亮蓝天光+雪峰棱面+飘雪）/ 昼夜循环（约 4 分钟流转的暮色渐层，夜里星点自然浮现）/ 远山萤火（两层山脊剪影+游弋萤火虫）/ 水下光影（斜向光柱漂移）。全部为渲染层程序生成，零素材。

**20 种元素** —— 沙/土/水/雪/冰/油/植物/木/石/蒸汽/火/烟/熔岩/火药/盐/酸/玻璃/电/金属/氢，各有密度、燃烧、腐蚀、栽培、融雪、导电、结冰等物理化学行为。

**电元素** —— 能量型元素，短寿命电火花在空中乱窜：**电×水**整片湖面通电，电弧沿波前炸裂传播、水面噼啪冒火花（电解）、偶发汽化成雨；**电×沙**雷击熔沙成闪玻璃（真实世界的闪电熔玻璃）；**电×火药**直接殉爆，通电水也能引爆水中火药；**电×植物**焦枯成烟；**电×雪**瞬时融水；电弧偶尔点燃油木（弱于明火）。通电的湖是活的——它导电、爆燥、还会下雨。

**⛓ 金属与氢** —— **金属**：静态固体建材，抗火抗爆（火药炸不动它），是唯一的导电结构——搭金属塔引雷、接通电路；**酸×金属**蚀刻冒泡、**熔岩×金属**缓慢熔成岩浆。**氢**：最轻气体，电解水会冒出氢气泡上浮聚集（电解真实耗水），氢包遇**明火/熔岩/电火花**轰然爆燃**还生成水**（氢氧相激，物质循环）——用电把水电解成氢，再用火把氢烧回水。

**❄ 冰与雪山** —— **冰**：静态固体，**水×冰**缓慢晶化蔓延、整湖从边缘悄悄冻实（冰湖凿开还会再冻上），明火/熔岩/盐/电都能融冰开路，火药爆破也能炸碎。**雪山**：第 8 张地图——冰岩尖峰+45° 雪裙+**冰川舌**（带冰裂缝）直下山脚+冰湖+**地热温泉**（泉眼持续冒蒸汽，蒸汽凝雨融雪，泉边四季不冻）+雪松林带；约 40 秒一轮**雪崩**（山体闷响前兆→雪瀑沿坡自上而下扫到坡脚，左右坡交替，搬运守恒不埋山），**单数轮中段刮暴风雪**（雪墙横扫全图）；**峰顶点火/引雷会提前引发雪崩**砸下来，是沙盒里第一种玩家可控的地形级灾害。陡坡覆静态冰壳、缓坡铺粉雪——坡度物理决定了雪只站在站得住的地方。

**八张初始地图，各自有性格与天象** —— 首次进入弹出地图选择，之后随时点「地图」换图重新生成：空白画布（自由创作）/ **青山林**（密林参天大树+苔石莲叶，晨雾漫林，阵雨过林润泽林木）/ **群岛**（沙岛礁石珊瑚+漂流浮木，每分钟交替海啸+周期雷暴+鲸群喷潮：闪电纵劈海面与沙岛，海面波前导电、沙滩烧出闪玻璃）/ **火山**（火山弹岩块+周期喷发：岩屑滚落前兆→熔岩柱冲天，火口熔岩呼吸鼓泡）/ **峡谷**（峭壁夹河+悬壁栈道，谷雾弥漫，岩壁剥落坠河）/ **沙漠**（沙丘埋油+绿洲+仙人掌+油泉露头，沙暴沙墙横扫）/ **玻璃之城**（玻璃幕墙高楼+天台花园+楼顶金属避雷针，雷暴夜闪电劈上天线、电流沿金属奔流）/ **雪山**（冰岩尖峰+冰川舌+冰湖+地热温泉，周期雪崩与暴风雪，山火雷鸣提前引发）。地图可带 tick 钩子做周期行为；底部工具栏随时一键恢复当前地图初始地形。全部按世界比例程序生成，横竖屏自适应。

**场景快照导出 + 3D 查看器** —— 底部工具栏的「快照」把当前世界导出为 JSON 快照（逐格物质 id + 调色板 + 自发光标记 + 版本/时间戳），配套 `viewer/` 下的离线 3D 查看器：双击打开、加载快照、旋转缩放、可调切片厚度与降采样。详见 `viewer/README.md`。

**3D 立体模式（测试版）** —— 头部按钮点开下拉菜单三选一，三种观赏对象任意直达：**火山岛**（程序生成的我的世界式俯瞰体素岛：中央高耸火山锥+火口熔岩湖+蜿蜒熔岩流+外圈森林带主河支流+随机树木+**草皮缀灌木野花、熔岩脉旁焦黑枯树、火山鸦绕火口盘旋、森林带萤火虫游弋**，方块从空中落下自主搭建；**喷发与 2D 火山 tick 同一时钟同步**——青烟前兆→熔岩柱冲天+飞溅熔岩滴+余烬火星常飘，伴低鸣环境音，昼夜主题下晨昏光色随 2D 流转）、**海岛**（程序化群岛立体沙盘：半透明海面下可见海床礁石藻斑，五座草顶沙岛错落分布、棕榈树弯干扇冠、草皮缀灌木野花，水下鱼群绕游、海面跃海豚与喷水鲸鱼、海鸥绕岛盘旋、波光粼粼；**海啸巨浪**：先海退骤降再多段波体压境，浪顶白沫翻卷、撞击段镜头微震、波前掠岛炸浪花，并伴浪涛拍岸声；**船队**六艘——大小帆船、渔船、载集装箱的货船、渔筏，海啸一定把它们推离航线，小船还有概率被掀翻沉没、之后重新浮起；**天气与 2D 群岛模拟真同步**——2D 海啸来时 3D 同侧起墙、2D 雷暴落雷位置逐道镜像天顶劈落，并伴合成雷声与海浪环境音；2D 图非群岛时走本地演出节奏）与 **实景同步**（把 2D 世界逐格挤出 4 层纵深的立体沙盘，每 120ms 差分同步——火山喷发、熔岩流动、一切反应实时映进 3D，新增方块坠落入场，熔岩/火焰自发光）。相机按对象自适应取景，可拖拽/缩放/自动旋转；「昼夜循环」主题下 3D 光照方位/色温/强度与 2D 同一时钟联动（正午炽白、暮色染橙、午夜星光）；观赏模式下暂停作画，模拟照常运行。3D 模块动态加载，首屏不背 three 的体积。

**世界分享码** —— 底部工具栏的「分享」打开分享面板：一键复制当前世界的分享码（RLE + 自定义头 + base64url，整个画面通常仅 1~2 KB 文本），发给朋友粘贴导入即可复现你的世界。屏幕尺寸不同会自动适配（水平居中、地形沉底），乱码/截断码一律拒绝导入。

**合成音效** —— WebAudio 全现场合成、零素材：倒料白噪按元素家族自动换滤波（粉末沙沙、液体低柔、固体钝刮）、爆炸低频闷响、新发现提示音、成就双音和弦。页头「音效」开关，偏好持久化。

**火药爆破** —— 火药殉爆会炸毁半径内固体方块（石/木/植物/玻璃/沙），连锁殉爆可炸出弹坑、拆建筑。爆炸带全套视觉反馈：白炽闪光、扩散冲击波环、放射火花粒子、镜头震动（节流防刷屏）。

## 运行

```bash
npm install
npm run dev            # 开发：http://localhost:5173
npm run build          # 构建产物到 dist/（纯静态，可部署任意静态托管）
npm run preview        # 本地预览构建产物
npm run build:single   # 生成「单文件版.html」（约 2MB，双击 file:// 即可玩）
```

**预览姿势**：双击打开「单文件版.html」最省事（所有代码内联在一个 HTML 里）；部署用 `dist/`。注意源码 `index.html` 必须配 Vite 开发服务器，直接双击或用普通静态服务器打开会白屏——若模块没跑起来，页面底部会自动浮出指引条而不是白屏。

## 操作

- **按住画布**涂抹当前元素，底部工具栏切换元素与笔刷大小
- 清空（两步确认）· 暂停（暂停时仍可布置场景）· 导出 PNG · 分享/导入世界码
- 页头开关合成音效 · 3D 立体模式（火山岛 / 海岛 / 实景同步）
- 世界每 4 秒自动存档到浏览器，下次打开自动恢复
- 打开发现图鉴查看已收集的反应配方

## 技术栈

Vite + Phaser 3（场景/输入壳）+ 自研细胞自动机（`src/sim/`）：

- `world.js` — Uint8Array 网格，每帧自底向上扫描、左右方向交替防漂移、moved 标记防重复更新
- `render.js` — 每格一像素写入 ImageData → CanvasTexture 放大绘制，16 档明度查找表 + 每粒子色偏实现颗粒质感
- `storage.js` — 世界 RLE 压缩存档 + 发现图鉴持久化（localStorage）
